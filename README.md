# AI Chatbot Website — Wajahat Irfan

A simple rule-based chatbot website. No AI model, no backend, no data sent anywhere.

## What it does

- Chat UI with a message window, input box, and send button.
- Rule-based replies (keyword matching) about:
  - Wajahat's skills
  - Cybersecurity tips
  - AI automation
  - His LinkedIn and GitHub links
  - His studies and projects
- Quick-reply buttons for common questions.
- A fallback reply for anything it doesn't understand.

## How to run

No build step and no backend. Either:

1. Open `index.html` directly in a browser, or
2. Serve it locally:

```bash
cd ai-chatbot-website
python3 -m http.server 8000
```

Then visit http://localhost:8000 in a browser.

## Skills shown

- HTML (chat layout, accessible form labels)
- CSS (chat bubbles, responsive layout)
- JavaScript (keyword matching, DOM updates, event handling, timed replies)
